# プロジェクトテンプレート

Claude と協働して作業を進めるプロジェクト用のフォルダテンプレートです。
資材・作業中ファイル・成果物を分けて管理し、人と Claude それぞれの作業ログを残せる構成になっています。

## 使い方

1. `プロジェクトテンプレート.zip` を展開する（または `プロジェクトテンプレート/` フォルダをコピーする）
2. フォルダ名をプロジェクト名に変更する
3. `01_資材/` に参照資料を配置して作業を開始する
4. Claude には展開したフォルダをワークスペースとして開かせる（`CLAUDE.md` のルールが読み込まれます）

## フォルダ構成

```
.
├── README.md                     # 本ファイル
├── プロジェクトテンプレート.zip     # テンプレート一式の配布用アーカイブ
└── プロジェクトテンプレート/
    ├── CLAUDE.md                 # Claude への作業ルール（作業ログの書き方など）
    ├── 01_資材/                  # 参照資料・インプット
    ├── 02_Claude作業フォルダ/     # Claude の作業領域
    │   └── Claude作業ログ.md      # Claude の作業ログ
    ├── 03_作業フォルダ/           # 人の作業領域
    │   └── 作業ログ.md            # 人の作業ログ
    └── 04_成果物/                 # 完成した成果物
```

## 各フォルダ・ファイルの説明

### `CLAUDE.md`

Claude が作業時に自動で読み込むルールファイルです。
現在は「依頼された作業が完了するたびに `02_Claude作業フォルダ/Claude作業ログ.md` へ作業ログを追記する」ルールと、そのフォーマットを定義しています。
プロジェクト固有のルール（用語、命名規則、禁止事項など）があればここに追記してください。

### `01_資材/`

プロジェクトのインプットとなる資料を置くフォルダです。
要件定義書、顧客からの受領資料、参考資料など、**原則として編集しない**元データを格納します。

### `02_Claude作業フォルダ/`

Claude が作業する際の作業領域です。下書き、中間ファイル、検証用ファイルなどを置きます。

- `Claude作業ログ.md` … Claude が依頼ごとに作業内容を追記するログ。フォーマットは `CLAUDE.md` を参照

### `03_作業フォルダ/`

人（担当者）が作業する際の作業領域です。

- `作業ログ.md` … 担当者の作業記録。書式は自由ですが、`Claude作業ログ.md` と同じフォーマットに揃えると時系列で追いやすくなります

### `04_成果物/`

レビュー済み・完成版の成果物を置くフォルダです。
作業フォルダで仕上げたものをここへ移動（またはコピー）して、最終版を明確に区別します。

## 作業ログのフォーマット

`Claude作業ログ.md` は以下の形式で末尾に追記されます（既存ログは書き換えません）。

```markdown
## YYYY/MM/DD HH:MM 作業タイトル

- 依頼内容: 何を頼まれたか
- 実施内容: 何をしたか
- 成果物: 作成・更新したファイル（なければ「なし」）
- 備考: 未完了事項・次回作業・注意点（なければ省略可）
```

## 補足

- Git は空フォルダを管理しないため、リポジトリをクローンした場合 `01_資材/` と `04_成果物/` が存在しないことがあります。必要に応じて作成するか、zip から展開してください。
- テンプレートを更新した場合は、`プロジェクトテンプレート.zip` も作り直して内容を揃えてください。
